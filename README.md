# Sadibek Nurmukhambet — Portfolio

A premium, animated personal portfolio built with Next.js, Tailwind CSS, Framer Motion, and Three.js.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- **Next.js 15** (App Router) + TypeScript
- **Tailwind CSS v4** + Shadcn UI conventions
- **Framer Motion** — scroll & entrance animations
- **Three.js** — shader hero background
- **lucide-react** — icons

## Deploy

```bash
npm run build
npm start
```

Deploy to [Vercel](https://vercel.com) with zero config.
